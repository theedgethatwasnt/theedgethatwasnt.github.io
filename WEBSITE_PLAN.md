The book's companion site: landing page → 81-experiment explorer (drill-down: description,
method, data, indicators, algorithms, key numbers, figures, code links) → glossary (hover
tooltips, click-through entries, indicator charts) → this curated code repo. Everything lives

## Canonical address & the immutability constraint
The book is PRINT: the URL it carries can never be changed. Therefore the printed address must
be a domain the AUTHOR OWNS — never a platform subdomain (github.io etc.), which dies with the
platform relationship. Candidate confirmed available at the registry (2026-07-07):
**theedgethatwasnt.com** (also .net, edgethatwasnt.com free; .ch optional as unstoppable mirror).

## Security / takedown-resilience stack (motivated by a prior overbroad DMCA against the author)
Layered by where jurisdiction actually bites:
1. **Registry (immovable):** .com = Verisign (US) regardless of registrar — US court orders reach
   it; realistic risk for a memoir companion ≈ nil. True insulation only via ccTLD (.ch/.is/.de).
2. **Registrar (chosen):** EU registrar — INWX (DE) or Gandi (FR); WHOIS privacy ON. NOT Njalla
   (it registers domains in ITS OWN name — you would not own the book's address).
3. **Host (biggest practical win):** EU-soil host — DMCA robo-notices don't apply; substantiated
   EU legal process required. Primary: Cloudflare Pages (free, fast) OR Hetzner Falkenstein
   (€4/mo, German company + German soil — NOTE pod-agent VPS is Hetzner-ASHBURN = US soil, don't
   confuse). Domain ownership makes hosts swappable in minutes; that's the real protection.
4. **GitHub demoted to mirror:** repo stays for discoverability; a repo takedown must not touch
   the site. Optional second code mirror: Codeberg/GitLab.
5. **Posture:** the author owns 100% of the content; any copyright claim is facially false and
   counter-noticeable. The stack buys continuity during nuisance, not concealment.

## Decisions made
- Chips (indicators/algorithms) = click-to-filter navigation; prose jargon links = glossary
  learning path (tooltip → entry → chart). Code-link hit area shrink-wraps to text.
- Every clickable INDICATOR term gets a relevant chart in its glossary entry (existing
  visual_ref_*/enc_* plates first; missing ones generated in-style from a small committed price
  sample so the site is reproducible standalone). Concept terms stay text-only.
- Site inherits the book's rules: no "honest", figure-text correspondence, receipts posture,
  not-financial-advice footer, OANDA named only positively (deficiencies = "retail FX").
